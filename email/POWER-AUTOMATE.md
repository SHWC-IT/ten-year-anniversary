# Power Automate build reference

How the anniversary invitation flow is put together: every action, setting, and expression.

This is the "how it works" document. For the numbered steps to actually send, follow
[SEND-DAY-CHECKLIST.md](SEND-DAY-CHECKLIST.md) instead.

---

## What the flow does

```
Manual trigger  (TestMode, TestAddress, MaxToSend)
      |
Get file content using path        <- anniversary-invite.html from SharePoint
      |
Compose  TemplateHtml              <- decode it to a string
      |
List rows present in a table       <- Contacts table, only Status = Ready
      |
Apply to each  (sequential)
      |-- Compose  SafeName        <- first name, or "Friend" if blank
      |-- Compose  RecipientAddress<- TestAddress in test mode, else the real one
      |-- Compose  PersonalHtml    <- replace the two tokens
      |-- Scope    Try   -> Send an email from a shared mailbox (V2)
      |-- Scope    Catch -> Update a row  (Status = Error, LastError)
      |-- Condition       -> Update a row  (Status = Sent, SentAt)   [live sends only]
      |-- Delay 3 seconds          <- keeps us under 30 messages/minute
      |
Send an email (V2)                 <- summary to yourself
```

The `Status` column is what makes this safe. Only `Ready` rows are picked up, and each row flips
to `Sent` immediately after its email goes out, so an interrupted run resumes exactly where it
stopped and nobody is emailed twice.

## Prerequisites

1. **The two files in SharePoint**, in the same document library folder:
   - `SEND - 10 Year Anniversary.xlsx`, generated by `email/tools/build-list.py`
   - `anniversary-invite.html`, the template from this directory

   OneDrive for Business works too, but SharePoint is better here because the whole team can
   reach it and it does not depend on one person's account.

2. **Send As permission** on `info@theshepherdshouse.church` for the account that will own the
   flow. Exchange admin center, Mailboxes, pick the shared mailbox, Delegation, add the account
   under **Send As**.

   Send As and Send on Behalf are not interchangeable. With only Send on Behalf, recipients see
   "your name on behalf of Shepherd's House Worship Center", which looks like a mistake. Send As
   shows the shared mailbox cleanly.

3. **The workbook must be closed** in the Excel desktop app, and not checked out in SharePoint.
   The Excel connector fails on a locked file. A `~$` prefixed file next to it means it is still
   open somewhere.

4. Connections used: **Excel Online (Business)**, **SharePoint**, **Office 365 Outlook**.

## Step 1: trigger

Action: **Manually trigger a flow**

Add three inputs, in this order, because the expression keys below depend on the order and type:

| Order | Type | Name | Expression key |
|---|---|---|---|
| 1 | Yes/No | `TestMode` | `triggerBody()?['boolean']` |
| 2 | Text | `TestAddress` | `triggerBody()?['text']` |
| 3 | Number | `MaxToSend` | `triggerBody()?['number']` |

If you are ever unsure of a key, pick the input from the dynamic content panel rather than typing
the expression by hand.

## Step 2: read the template

Action: **SharePoint, Get file content using path**

- Site Address: the church SharePoint site
- File Path: `/Shared Documents/Anniversary Email/anniversary-invite.html`

Leave the action name at its default so the expression below matches.

## Step 3: decode it to a string

Action: **Compose**, renamed to exactly `TemplateHtml`

```
string(outputs('Get_file_content_using_path')?['body'])
```

This is the form that works on the church tenant, confirmed on the first build. The SharePoint
action's **Infer Content Type** setting defaults to Yes, so it recognises the `.html` file as text
and returns the decoded string directly.

Verify it by opening the run history and reading the action's Outputs. It should begin with
`<!DOCTYPE html`. Two ways it can go wrong:

- Outputs are a wall of letters and digits with no angle brackets, meaning the content arrived
  base64 encoded. Use `base64ToString(outputs('Get_file_content_using_path')?['body'])`.
- The run fails with *"property '$content' cannot be selected. Property selection is not supported
  on values of type 'String'"*. That is the older
  `base64ToString(...?['body']?['$content'])` form being used against a connector that already
  decoded the file. Switch to the expression above.

Renaming Compose actions matters: `outputs('TemplateHtml')` only resolves if the action carries
that name. Spaces in an action name become underscores in expressions.

## Step 4: read the contacts

Action: **Excel Online (Business), List rows present in a table**

- Location / Document Library / File: the uploaded workbook
- Table: `Contacts`
- **Filter Query**: `Status eq 'Ready'`
- **Top Count**: `triggerBody()?['number']`

Then open the action's **Settings** and turn **Pagination ON** with a threshold of `5000`.

This one is easy to miss and it silently truncates: without pagination the action returns at most
256 rows. The list is 212 today, so it happens to fit, but it will not once the list grows, and
the failure mode is a quiet partial send rather than an error.

## Step 5: loop over the contacts

Action: **Apply to each**, over the `value` output of Step 4.

Open **Settings** and confirm **Concurrency Control is OFF**. Sequential is the point: parallel
branches would blow straight through Exchange Online's 30 messages per minute limit and start
getting throttled.

### 5a. Compose, renamed `SafeName`

```
if(empty(trim(coalesce(item()?['FirstName'],''))),'Friend',trim(item()?['FirstName']))
```

Today every row has a first name, so this never fires. It exists so that a future blank cell
produces "Hello Friend," instead of "Hello ,".

### 5b. Compose, renamed `RecipientAddress`

```
if(equals(triggerBody()?['boolean'],true),triggerBody()?['text'],item()?['EmailAddress'])
```

This single expression is what makes test runs safe. In test mode every message goes to your own
address and no member is contacted.

### 5c. Compose, renamed `PersonalHtml`

```
replace(replace(outputs('TemplateHtml'),'{{FirstName}}',outputs('SafeName')),'{{EmailAddress}}',item()?['EmailAddress'])
```

Note the inner replace uses `SafeName`, the outer one uses the raw address. `{{EmailAddress}}`
appears only inside the unsubscribe mailto link, so a reply identifies who wants off the list.

Verify these two tokens are the only ones in the template before you build the flow:

```
python3 email/tools/render-preview.py --check
```

### 5d. Scope, renamed `Try`

Inside it, one action: **Office 365 Outlook, Send an email from a shared mailbox (V2)**

| Field | Value |
|---|---|
| Original Mailbox Address | `info@theshepherdshouse.church` |
| To | `outputs('RecipientAddress')` |
| Subject | `You are invited: Shepherd's House 10th Anniversary, October 9 - 11` |
| Body | `outputs('PersonalHtml')` |
| Reply To (advanced) | `info@theshepherdshouse.church` |
| Importance (advanced) | Normal |

**The Body field needs the code view.** It opens as a rich text editor, and pasting an expression
into it leaves you emailing raw HTML markup as visible text. Click the `</>` button in the Body
field's toolbar first, then put the expression in. This action sends HTML by default, so there is
no separate "Is HTML" toggle to find.

### 5e. Scope, renamed `Catch`

Configure run after: check **has failed** and **has timed out**, uncheck **is successful**.

Inside it, **Excel Online (Business), Update a row**:

| Field | Value |
|---|---|
| Key Column | `ContactID` |
| Key Value | `item()?['ContactID']` |
| Status | `Error` |
| LastError | see below |

```
coalesce(first(result('Try'))?['error']?['message'],'Send failed, see the run history')
```

Without this, a single bad address leaves its row sitting at `Ready`, and the next run tries it
again forever. Marking it `Error` takes it out of the rotation and records why.

### 5f. Condition, then Update a row

Condition: `triggerBody()?['boolean']` **is equal to** `false`

In the **If yes** branch, **Excel Online (Business), Update a row**:

| Field | Value |
|---|---|
| Key Column | `ContactID` |
| Key Value | `item()?['ContactID']` |
| Status | `Sent` |
| SentAt | `convertTimeZone(utcNow(),'UTC','Eastern Standard Time','yyyy-MM-dd HH:mm')` |

The condition is why test runs leave the spreadsheet untouched, which is what lets you re-run
them as many times as you like.

### 5g. Delay

Action: **Delay**, 3 seconds. That paces the send at 20 messages per minute against a 30 per
minute ceiling, leaving headroom for anything else the tenant is sending.

## Step 6: summary to yourself

After the loop, **Office 365 Outlook, Send an email (V2)** to your own address:

```
Rows picked up: @{length(outputs('List_rows_present_in_a_table')?['body/value'])}
```

Cheaper than scrolling the run history to find out whether it finished.

## Limits, and why this list fits inside them

| Limit | Value | This send |
|---|---|---|
| Exchange Online recipients per day | 10,000 | 212 |
| Exchange Online messages per minute | 30 | 20 by design |
| Recipients per message | 500 | 1 |
| Power Automate actions per 5 minutes (Office 365 tier) | 6,000 | about 1,500 in total |
| Excel connector rows without pagination | 256 | 212, so turn pagination on anyway |

Roughly 11 minutes end to end at 3 seconds per message.

If the list ever passes about 2,000 people, split it across days by setting `Status` to `Hold` for
a portion and releasing a batch at a time, or move to a real mail platform (see below).

## Deliverability checklist

Do these before the real send. They matter more than anything in the template.

- [ ] **DKIM is enabled for `theshepherdshouse.church`.** It is **off by default** on custom
      domains. Microsoft Defender portal, Policies and rules, Threat policies, Email
      authentication settings, DKIM. Flip the domain to Enabled and publish the two CNAMEs it
      asks for.
- [ ] **SPF** TXT record includes Microsoft: `v=spf1 include:spf.protection.outlook.com -all`
- [ ] **DMARC** exists, even permissively: `v=DMARC1; p=none; rua=mailto:info@theshepherdshouse.church`
- [ ] Seed test includes a **liberty.edu** address. 66 of the 212 recipients are behind that
      institutional filter, so it is the single biggest block that could quarantine.
- [ ] The From address is a **real monitored mailbox**, so replies and bounces are seen.
- [ ] No link shorteners anywhere in the email. Bare shortened links are a strong spam signal.
- [ ] Physical address and an unsubscribe path are present. Both are in the template footer
      already, and both are CAN-SPAM requirements for this kind of mail.

## Unsubscribes and bounces

The Outlook connector cannot set a `List-Unsubscribe` header, so there is no one-click
unsubscribe button in Gmail. The template uses a mailto link instead, pre-filled with the
recipient's address.

Handle them manually, which at this list size is a few minutes of work:

1. Watch `info@theshepherdshouse.church` for replies with "Unsubscribe" in the subject.
2. Set that person's `Status` to `Unsubscribed` in the workbook.
3. The `Status eq 'Ready'` filter excludes them from every future send automatically.

Do the same for hard bounces, using `Bounced`. Keep the row rather than deleting it, so you have
a record of why that person stopped receiving mail.

## Sending the follow-up

`anniversary-followup.html` is a second template for the same list, meant for a few weeks before
the weekend. It asks anyone who has not registered to do so, thanks those who have, and points
both groups at the anniversary collection in the store and at giving. It uses the same two tokens
as the invitation, so the flow itself needs only two changes:

| Where | Change to |
|---|---|
| Step 2, File Path | `/Shared Documents/Anniversary Email/anniversary-followup.html` |
| Step 5d, Subject | `Have you registered? Shepherd's House 10th Anniversary, October 9 - 11` |

The cleanest way to make them is **Save As** on the invitation flow, so the original stays exactly
as it ran and the copy carries the follow-up's path and subject.

The `Status` column also needs resetting before the send. Every row the invitation reached reads
`Sent`, and the flow only picks up `Ready`. Either edit the workbook where it sits, in Excel for
the web, replacing `Sent` with `Ready` in the `Status` column and clearing `SentAt`, or work on a
local copy:

```
python3 email/tools/set-status.py --reset-sent
```

Both leave `Unsubscribed`, `Bounced`, and `Error` rows untouched, so nobody who asked to stop, or
whose address failed, is mailed again. If you want to keep the invitation's timestamps, save a copy
of the workbook first.

Verify the template's tokens the same way as the invitation:

```
python3 email/tools/render-preview.py --check --template email/anniversary-followup.html
```

The step by step is [SEND-DAY-CHECKLIST.md](SEND-DAY-CHECKLIST.md), Part F.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| Recipients see literal `{{FirstName}}` | A Compose action is not named what the `replace()` expression references | Check the names in Steps 3, 5a, 5c match exactly |
| Email arrives as visible HTML markup | Body field was in rich text mode | Click `</>` in the Body field and paste the expression there |
| From shows "on behalf of" | Only Send on Behalf was granted | Grant **Send As** in Exchange admin center |
| Only 256 people got it | Pagination left off | Step 4 Settings, Pagination ON, threshold 5000 |
| "The resource is locked" or the workbook cannot be opened | The file is open in Excel, or checked out | Close Excel everywhere, delete any `~$` lock file, check the file back in |
| Action throttled, 429 responses | Concurrency on, or delay too short | Concurrency Control OFF, Delay at 3 seconds |
| "Key column values must be unique" | Duplicate or blank `ContactID` | Re-run `build-list.py`, which guarantees unique IDs |
| A row says `Sent` but nothing arrived | Message was accepted then filtered | Check the recipient's spam folder and the Defender message trace |
| Re-running sends duplicates | `Status` never flipped, usually the Condition in 5f is inverted | Confirm the condition is `TestMode is equal to false` |

## When to move off this flow

This is a good fit for a few hundred people once or twice a year. Consider moving if any of these
become true:

- The list passes roughly 2,000 people.
- You want open and click tracking, which the Outlook connector cannot provide.
- You want bounces and unsubscribes handled automatically instead of by hand.
- You start sending monthly or more often, where sender reputation needs real management.

The natural next step is **Elvanto's People email**, since the church already uses Elvanto for
the registration forms, so the membership data and unsubscribe state live in one place. Failing
that, most email service providers have a nonprofit tier.
